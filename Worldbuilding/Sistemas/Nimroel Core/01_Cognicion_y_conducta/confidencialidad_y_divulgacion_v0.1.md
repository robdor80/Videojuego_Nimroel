# Nimroel Core — confidencialidad y divulgación v0.1

## Autoridad

**CORE UNIVERSAL — namespace CONF**

Principios obligatorios:

- conocer una información no implica estar autorizado a divulgarla;
- contar algo a una persona no autoriza automáticamente su retransmisión;
- una confidencia puede ser parcial, condicionada o limitada a un círculo;
- escuchar o descubrir algo accidentalmente puede crear conocimiento sin crear permiso;
- una filtración requiere transmisión o exposición real;
- romper confidencialidad no difunde automáticamente la información a toda la población;
- la confidencialidad no define si el contenido es verdadero;
- la IA solo puede revelar información confidencial conocida y dentro de límites autorizados o de una ruptura validada.
