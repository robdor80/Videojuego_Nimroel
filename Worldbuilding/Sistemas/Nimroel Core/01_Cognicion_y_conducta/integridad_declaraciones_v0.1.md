# Nimroel Core — integridad de declaraciones v0.1

## Autoridad

**CORE UNIVERSAL — namespace STAT**

Principios obligatorios:

- una declaración no reescribe la verdad del World State;
- error sincero y falsedad deliberada son estados distintos;
- silencio, negativa y evasión no equivalen automáticamente a falsedad;
- una media verdad puede inducir una impresión engañosa sin contener una frase falsa;
- el oyente no recibe la intención interna del hablante como conocimiento;
- una versión mantenida debe conservar continuidad con declaraciones previas;
- descubrir una falsedad requiere evidencia, contradicción, admisión o información fiable;
- la IA no puede reescribir historial de declaraciones para evitar incoherencias.
