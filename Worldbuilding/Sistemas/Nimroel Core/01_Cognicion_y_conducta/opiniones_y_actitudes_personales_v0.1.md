# Nimroel Core — opiniones y actitudes personales v0.1

## Autoridad

**CORE UNIVERSAL — namespace VIEW**

VIEW representa una evaluación subjetiva mantenida por un actor sobre otra persona, lugar, institución, práctica, decisión o evento conocido.

Principios obligatorios:

- una opinión no es verdad objetiva;
- VIEW se separa de PREF, EMO, FRI, TRUST y reputación;
- pueden coexistir valoraciones distintas por dominio;
- una primera impresión puede ser débil y revisable;
- la ambivalencia es válida;
- una opinión privada no se difunde sola;
- rumores influyen solo si son recibidos y creídos;
- el tiempo no recalcula VIEW aleatoriamente;
- la IA puede usar una opinión para tono o desacuerdo, pero nunca presentarla como hecho objetivo.
