# Nimroel Core — identidad y roles personales v0.1

## Autoridad

**CORE UNIVERSAL — namespace SELF**

Principios obligatorios:

- SELF no equivale a empleo, reputación, personalidad ni estatus legal;
- un actor puede mantener varios roles identitarios importantes;
- perder un rol activo no borra inmediatamente su identidad asociada;
- un rol de legado puede seguir formando parte de la historia personal;
- SELF no crea por sí mismo parentesco, relación, empleo, autoridad o permiso;
- las transiciones identitarias requieren cambios vitales reales;
- memoria y World State conservan continuidad entre roles pasados y presentes;
- la IA no puede inventar una identidad central sin base biográfica o de World State.


---

## Integración con identidad nominal

El nombre civil y los alias se modelan mediante NAME.

SELF puede contener roles como:

- madre;
- capitán;
- artesano;
- heredero;
- viudo;

pero no posee autoridad para cambiar el nombre legal.

Cambiar de nombre no reescribe SELF ni crea una nueva persona.
