# Nimroel Core — expectativas y revisión v0.1

## Autoridad

**CORE UNIVERSAL — namespace EXP**

Principios obligatorios:

- expectativa no equivale a conocimiento del futuro;
- se forma desde experiencia, hábitos, confianza, memoria, fuentes y patrones conocidos;
- dos actores pueden esperar resultados diferentes del mismo acontecimiento;
- la incertidumbre es un estado válido;
- sorpresa requiere una discrepancia real entre expectativa previa y resultado conocido;
- una expectativa no se resuelve hasta que el actor conoce el resultado;
- una predicción fallida no prueba engaño;
- la revisión exige experiencia o evidencia suficiente, no acceso al futuro oculto del motor.
