# Nimroel Core — decisión, deliberación y riesgo v0.1

## Autoridad

**CORE UNIVERSAL — namespace DEC**

Una decisión se toma desde opciones conocidas, no desde la solución óptima que conoce el motor.

Principios obligatorios:

- hidden World State no entra como input privado;
- objetivos, obligaciones, emociones, personalidad y relaciones pueden competir;
- la indecisión es válida;
- riesgo real y riesgo percibido son distintos;
- elegir no ejecuta ni completa la acción;
- cambiar de opinión tras nueva información es coherente;
- una buena decisión puede salir mal y una mala decisión puede salir bien;
- offscreen no concede rutas, conocimiento ni optimización perfectos;
- la IA propone, el motor valida.
