# Nimroel Core — espera y capacidad efectiva de servicio v0.1

## Autoridad

**CORE UNIVERSAL — namespace WAIT**

Principios obligatorios:

- WAIT01–WAIT08 conservan exactamente su significado;
- un servicio requiere actor capaz, lugar, tiempo, recursos y disponibilidad;
- no existe una cola FIFO universal ni un sistema moderno de tickets por defecto;
- el jugador no tiene prioridad metafísica;
- llegada, urgencia, compromiso previo, relación, naturaleza del servicio, autoridad legítima, capacidad y contexto pueden alterar el orden;
- una espera ocurre en un lugar y consume tiempo real;
- edificio abierto no equivale a atención inmediata;
- plantilla teórica no equivale a capacidad efectiva;
- cierre, ausencia o falta de recursos pueden diferir una solicitud, no completarla;
- una negativa no implica hostilidad automáticamente;
- las solicitudes relevantes sobreviven LOD y save/load;
- la IA no puede crear ni borrar esperas para favorecer o bloquear al jugador.
