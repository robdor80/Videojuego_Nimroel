# Nimroel Core — aprendizaje de oficio y transmisión de habilidad v0.1

## Autoridad

**CORE UNIVERSAL — namespace APR**

Principios obligatorios:

- APR01–APR06 conservan sus significados;
- el tiempo por sí solo no concede competencia;
- progresar exige práctica, variedad, supervisión, resultados, corrección, herramientas, materiales y tiempo efectivo;
- poseer herramientas no demuestra habilidad;
- un aprendiz puede contribuir a producción real sin equivaler automáticamente a un trabajador plenamente competente;
- las tareas permitidas dependen del estado de aprendizaje y del riesgo;
- ser buen profesional no garantiza ser buen mentor;
- cambiar o perder mentor no borra aprendizaje previo;
- una interrupción no reinicia el progreso;
- APR06 significa práctica independiente dentro de competencia real, no maestría excepcional;
- no se presupone examen, certificado, gremio ni herencia familiar obligatoria;
- enseñar consume atención del mentor;
- la IA no puede transferir instantáneamente un oficio complejo mediante diálogo.
