# Nimroel Core — transacciones, obligaciones y registros v0.1

## Estado

**CORE UNIVERSAL ACTIVO**

Este contrato no inventa impuestos ni moneda. Define la mecánica universal necesaria para que una obligación económica exista y pueda pagarse, registrarse, auditarse o incumplirse.

## Principios

- el valor transferido debe existir;
- pagar mueve recursos reales;
- una obligación tiene base, autoridad/acreedor, responsable y estado;
- puede existir pago parcial;
- el registro contable no crea el pago;
- un libro puede contener errores, retrasos o fraude;
- una auditoría compara fuentes y puede descubrir discrepancias;
- fuera de cámara se conservan las mismas obligaciones y saldos.

## Medios de cumplimiento

Un perfil cultural puede permitir:

- moneda canónica;
- bienes en especie;
- materiales;
- alimentos o producción;
- trabajo/servicio;
- combinación de varios.

## Separación de realidad y registro

El World State distingue:

1. lo que realmente se transfirió;
2. lo que debía transferirse;
3. lo que el funcionario escribió;
4. lo que la autoridad sabe.

Esto permite deuda, error, corrupción, contrabando, recibos falsos y auditorías sin otorgar omnisciencia al sistema.

## Regla final

**Un impuesto, tasa, salario o pago no es un número que desaparece: es una obligación o transacción causal que modifica recursos persistentes y puede dejar documentación.**
