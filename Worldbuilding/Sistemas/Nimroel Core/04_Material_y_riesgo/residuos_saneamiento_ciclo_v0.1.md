# Nimroel Core — residuos, saneamiento y ciclo de retirada v0.1

## Autoridad

**CORE UNIVERSAL — namespaces WASTE / WST**

Principios obligatorios:

- WASTE01–WASTE08 y WST01–WST07 conservan sus significados;
- el Core define generación, contención, recogida, transporte, reutilización, eliminación y acumulación problemática;
- no impone un tipo universal de alcantarillado, letrina ni organización municipal;
- retirar residuos exige actor o trabajador, manipulación/contenedor, ruta y destino;
- lluvia o LOD no eliminan mágicamente residuos;
- residuos recuperables pueden reutilizarse sólo cuando exista un destino real;
- acumulación puede afectar olor, obstrucción, insectos, presión sanitaria futura y reputación local;
- el Core no crea enfermedad automática sin sistema de salud;
- los lotes relevantes y las acumulaciones problemáticas persisten;
- capacidad de contenedores es finita;
- ubicaciones de vertido, infraestructura sanitaria y organización concreta pertenecen a defaults o contenido local.
