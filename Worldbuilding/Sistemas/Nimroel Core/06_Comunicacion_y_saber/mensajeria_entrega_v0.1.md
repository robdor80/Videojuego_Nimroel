# Nimroel Core — mensajería, cartas y entrega v0.1

## Autoridad

**CORE UNIVERSAL — namespace MSG**

Principios obligatorios:

- MSG01–MSG05 conservan sus significados;
- el Core no presupone un servicio postal concreto;
- comunicación física no es instantánea;
- entregar no equivale a leer y existir no equivale a ser conocido;
- mensajes conservan remitente, portador, destinatario, tiempos, poseedor actual, estado y confidencialidad cuando son relevantes;
- alfabetización puede resolverse mediante mensaje oral, lector de confianza o escriba cuando el contexto lo permita;
- el portador sólo conoce contenido al que realmente tuvo acceso;
- ruta y conocimiento de destino afectan la entrega;
- urgente sigue necesitando tiempo de viaje;
- un aviso público sólo se convierte en conocimiento tras exposición real;
- un mensaje en tránsito nunca actualiza automáticamente el conocimiento del destinatario;
- mensajes significativos pueden persistir como objeto o registro.
