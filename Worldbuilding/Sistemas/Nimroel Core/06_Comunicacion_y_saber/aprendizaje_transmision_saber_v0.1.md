# Nimroel Core — aprendizaje y transmisión de saber v0.1

## Autoridad

**CORE UNIVERSAL — namespace ED**

Principios obligatorios:

- ED01–ED07 conservan sus significados;
- el Core no impone una red escolar, tasa universal de alfabetización ni duración única de aprendizaje;
- el saber puede proceder de familia, maestro, experiencia, documento, institución o rumor;
- texto de lore existente no equivale automáticamente a conocimiento de un NPC;
- una conversación no transfiere instantáneamente dominio técnico complejo;
- progreso profesional puede depender de tiempo, práctica, tareas, enseñanza y experiencia;
- muerte o ausencia de un maestro no borra lo ya aprendido;
- progreso offscreen exige formación o práctica compatible realmente disponible;
- currículos, instituciones, vivienda de aprendices y cultura educativa concreta pertenecen al reino/territorio.
