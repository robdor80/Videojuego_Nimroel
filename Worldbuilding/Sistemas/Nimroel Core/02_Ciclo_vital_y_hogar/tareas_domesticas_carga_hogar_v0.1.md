# Nimroel Core — tareas domésticas y carga del hogar v0.1

## Autoridad

**CORE UNIVERSAL — namespaces CHORE / DOM**

Principios obligatorios:

- las tareas domésticas consumen tiempo y recursos reales;
- no se asignan automáticamente por sexo;
- edad, capacidad, disponibilidad, trabajo, relación, preferencias, costumbre, habilidad y salud pueden influir;
- niños sólo realizan tareas compatibles con su desarrollo;
- agua, combustible, comida, lavado, residuos, cuidados, recados y mantenimiento dependen de sus sistemas propietarios;
- ayuda doméstica exige una persona o servicio real;
- huéspedes, ausencias y crisis pueden alterar la carga;
- riqueza puede comprar apoyo, pero no elimina logística ni tiempos;
- el backlog persiste entre guardados y debe ser compatible con el estado materializado;
- LOD bajo sólo puede resolver tareas con actores, tiempo, recursos y acceso plausibles.
