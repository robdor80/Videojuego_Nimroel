# Nimroel Core — dependientes y red de cuidados v0.1

## Autoridad

**CORE UNIVERSAL — namespaces DEP / CARE**

Principios obligatorios:

- dependencia y cobertura de cuidados son World State persistente;
- edad avanzada no crea dependencia automática;
- un niño no usa el modelo de rutina de un adulto;
- cuidar consume tiempo, presencia, espacio, alimento, descanso y organización;
- familiares y vecinos sólo ayudan si existe relación, presencia, capacidad y disponibilidad reales;
- un hueco de cuidado no crea por sí solo daño sanitario: salud conserva su autoridad;
- ayuda externa requiere un actor o servicio real;
- reubicar a una persona para recibir cuidados usa MOVE y RES;
- el Core no fija un modelo institucional universal de guardería o residencia;
- la IA no puede ignorar una dependencia alta por conveniencia.
