# Nimroel Core — envejecimiento, capacidad y actividad en la vejez v0.1

## Autoridad

**CORE UNIVERSAL — namespace AGE**

Principios obligatorios:

- AGE no impone una línea rígida ni umbrales numéricos universales;
- edad no equivale automáticamente a dependencia, desempleo, pérdida de habilidad o muerte;
- capacidad física puede cambiar separadamente del conocimiento, experiencia y juicio;
- la actividad puede adaptarse en horas, tareas, desplazamiento, esfuerzo, supervisión o mentoría;
- el Core no presupone edad universal de jubilación ni sistema universal de pensiones;
- dependencia solo aparece cuando existe necesidad real de asistencia;
- propiedad, negocio, relaciones, memoria y reputación persisten durante el envejecimiento;
- la vejez puede mantener trabajo, cuidado, sociabilidad y transmisión de saber;
- el envejecimiento offscreen exige progresión temporal válida;
- la IA no puede inferir senilidad, fragilidad o dependencia solo por la edad.
