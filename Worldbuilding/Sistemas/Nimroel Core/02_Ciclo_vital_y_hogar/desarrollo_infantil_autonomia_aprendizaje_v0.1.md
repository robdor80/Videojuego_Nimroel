# Nimroel Core — desarrollo infantil, autonomía y aprendizaje v0.1

## Autoridad

**CORE UNIVERSAL — namespace CHD**

Principios obligatorios:

- CHD preserva npc_id, memoria, personalidad y parentesco a través del desarrollo;
- las edades numéricas exactas pertenecen al sistema de ciclo vital, no a este contrato;
- autonomía depende de desarrollo, salud, red de cuidados, riesgo, conocimiento de rutas, hora y eventos;
- un niño no usa por defecto el modelo de rutina ni la carga laboral de un adulto;
- contribución doméstica, aprendizaje y exposición a oficios crecen de forma gradual y causal;
- aprendizaje cotidiano, juego, mentoría y aprendizaje formal siguen sus sistemas propietarios;
- conocimiento infantil necesita una fuente plausible;
- progresión visual y material debe conservar la identidad del NPC;
- el desarrollo offscreen exige tiempo de ciclo vital válido;
- la IA no puede adelantar una etapa por conveniencia narrativa.
