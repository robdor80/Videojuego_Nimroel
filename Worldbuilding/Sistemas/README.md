# Sistemas globales de Nimroel

Este árbol contiene reglas reutilizables que no pertenecen a un reino o ciudad concretos.

## Autoridad

La jerarquía objetivo es:

**Nimroel Core → defaults culturales del reino → territorio/casa → override local → World State de partida**

Los sistemas Core definen comportamiento universal.

Los niveles inferiores solo pueden:

- aportar parámetros;
- añadir contenido cultural;
- restringir o especializar;
- declarar excepciones explícitas compatibles.

No deben duplicar como autoridad activa una regla ya migrada al Core.
