# Aldeas canónicas concretas

## Propósito

Esta carpeta contendrá las aldeas **reales y con nombre** que formen parte del mapa de Nimroel.

Una instancia no debe repetir toda la definición genérica.

Debe indicar:

- qué modelo utiliza;
- qué variaciones introduce;
- dónde se encuentra;
- qué familias y NPC viven allí;
- qué edificios concretos posee;
- qué elementos narrativos o de gameplay la distinguen.

## Ejemplo futuro

```text
Nombre_de_aldea/
├── aldea.md
├── npc.md
└── gameplay.md
```

El archivo `aldea.md` deberá enlazar al modelo correspondiente, por ejemplo:

`Modelo base: V1_Mixta_maderera_agricola`
