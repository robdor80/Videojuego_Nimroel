# Aldea tipo Valrik

## Estado

**BASE APROBADA — DESARROLLO PENDIENTE**

Este documento servirá como plantilla jugable para definir la lógica espacial, funcional y visual de una aldea típica del territorio Valrik.

Su objetivo es poder reutilizar una misma identidad regional en distintas aldeas sin repetir exactamente la misma distribución.

## Uso previsto

- diseño de aldeas para gameplay;
- base para distribución de casas, talleres y servicios;
- apoyo para construcción de niveles;
- referencia para futuras variantes de aldeas;
- base para prompts visuales y vistas aéreas.

## Próximo paso

Definir la **lógica básica de la aldea principal de la v0.0.1** de forma breve y funcional antes de convertirla en un plano más concreto.
