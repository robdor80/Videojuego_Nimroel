# Modelos de aldeas Valrik

## Propósito

Esta carpeta contiene **variantes reutilizables** de la aldea tipo Valrik.

Cada modelo define una combinación de función económica, servicios y lógica espacial que puede reutilizarse en más de una aldea real.

## Convención

`V1`, `V2`, `V3`... son **identificadores de modelo**.

No significan versión documental.

Las revisiones internas de un documento, si fueran necesarias, usarán nomenclatura como `v0.1`, `v0.2`, etc.

## Modelos actuales

### V1 — Mixta maderera y agrícola

Aldea interior pequeña situada en una ruta importante de transporte de madera, con agricultura y ganadería local, posada, herrero, aserraderos, carpintería y servicios ligados al tránsito.

### V2 — Molino y agroganadería

Aldea interior pequeña con agricultura y ganadería local cuyo servicio distintivo es el molino. No dispone de posada ni herrería y depende de la red de aldeas cercana.

## Evolución futura

Cada modelo podrá incorporar cuando sea necesario:

- `modelo.md` — definición funcional;
- `layout.md` — plano y reglas espaciales;
- `Datos operativos/` — futura representación estructurada para el motor.

No se crearán datos técnicos antes de que la lógica de cada modelo esté suficientemente cerrada.
