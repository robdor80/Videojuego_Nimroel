# Prompt visual — Aldea Valrik

## Estado

**ESTRUCTURA APROBADA — DESARROLLO PENDIENTE**

Este documento servirá para transformar el lore funcional de las aldeas Valrik en prompts visuales consistentes.

## Uso previsto

Se utilizará como base para crear:

- vistas aéreas de aldeas;
- imágenes de contexto del juego;
- exteriores de edificios;
- interiores de edificios;
- escenas rurales;
- referencias visuales para construcción en el motor.

## Elementos que se desarrollarán

- disposición general de la aldea;
- arquitectura;
- materiales;
- caminos;
- casas familiares;
- posada/taberna;
- herrería;
- carpintería;
- aserraderos;
- molino;
- establos y corrales;
- campos y huertos;
- iluminación, clima y entorno;
- variaciones visuales según el tipo de aldea.

Los prompts se redactarán después de cerrar la lógica espacial y funcional de la aldea tipo.
