# Territorio de Treskal — Estructura de asentamientos

## Estado

**CANON BASE APROBADO**

## Terminología

- **Valrik** es la Gran Casa gobernante.
- **Treskal** es la ciudad principal y da nombre de referencia al territorio y a su zona cultural inmediata.
- La carpeta `Casa Valrik` del repositorio representa la administración política, no el nombre de una región étnica o geográfica independiente.

## Rangos canónicos de población

Estos límites se aplican al **territorio de Treskal**:

| Tipo | Población / dotación |
|---|---:|
| Aldea | 35–100 habitantes |
| Pueblo | 350–900 habitantes |
| Villa | 2.000–4.500 habitantes |
| Treskal | 12.000–18.000 habitantes |
| Puesto de guardia fronterizo | 8–20 guardias permanentes |

Estos rangos no deben extrapolarse automáticamente al conjunto de Norgard.

## Principio de diseño

En esta fase se construye únicamente el **esqueleto mínimo** de cada categoría.

El orden de trabajo será:

1. **Aldea** — estructura mínima.
2. **Pueblo** — estructura mínima.
3. **Villa** — estructura mínima.
4. **Treskal** — estructura mínima de la ciudad única del territorio.

Después se añadirán:

1. posibilidades opcionales;
2. dependencias entre asentamientos;
3. probabilidades y pesos;
4. reglas de cobertura regional;
5. datos operativos para el motor.

## Puestos de guardia

Los puestos de guardia fronterizos no son asentamientos civiles.

Se consideran instalaciones funcionales con una dotación permanente de **8–20 guardias**, cuya composición concreta, edificios y refuerzos se definirán en una fase posterior.


## Metodología común

Todos los tipos de asentamiento se desarrollarán con la misma secuencia:

**esqueleto mínimo → posibilidades → coherencia regional → probabilidades → generación → persistencia**.

La metodología completa queda definida en:

`metodologia_generacion_asentamientos_treskal.md`

Esta regla debe mantenerse para aldea, pueblo, villa, Treskal y, con las adaptaciones necesarias, los puestos de guardia fronterizos.
