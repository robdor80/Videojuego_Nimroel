| security | Autoridad de Guardia urbana, Casa y Armada Real separada; no nuevo cuerpo militar | Necesita evidencia local y/o Core para materialización |
| care | Salud, cuidados y dependencia sin hospital o cuidador universal por plantilla | Necesita evidencia local y/o Core para materialización |
| relationships | Core hereda parentesco, reputación, conocimiento, memoria, diálogo y consentimientos | Necesita evidencia local y/o Core para materialización |
| maintenance | Agua, saneamiento, incendios, desgaste y combustible solo con infraestructura específica o estado UNKNOWN | Necesita evidencia local y/o Core para materialización |
| worldstate | Entidades, ubicaciones, accesos, actividades y cambios persisten solamente cuando CoreRPG los ejecuta | Necesita evidencia local y/o Core para materialización |

La matriz permite **evaluar** decisiones futuras, pero no decreta físicamente un hospital, mercado, puente, puerto nuevo, aduana independiente, cuartel o barrio. Los sistemas universales como K, MEM, EMP, RES, OWN, WAIT, CARE y FIRE deben leerse desde Nimroel Core/Norgard, respetando el principio de no duplicación de Valrik.
