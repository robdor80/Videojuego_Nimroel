# D.P16 — Treihord: inventario funcional previo al diseño urbano

**Fuente de autoridad:** perfil D07 + D08 + D09 + D10 + Norgard; **estado:** diseño funcional condicional, no nuevo canon urbano.

## Anclas cerradas

- capital de Casa Darovan
- diseño base canónico cerrado, ocho barrios/cuatro plazas/cuatro puertas
- Crisol ensaya y refina, no acuña
- Belara junto a ciudad; barcazas industriales someras
- Bóveda del Grifo y galería La Vena con accesos protegidos

**Población:** aproximadamente 32000 habitantes según el canon base. Se diferencian las cifras de residentes de la cantidad real de hogares, tiendas o trabajadores, que no se infiere.

**Ocho barrios canónicos intocables:** El Recinto, Los Altos, El Peso, Las Lonjas, Los Oficios, La Calzada, La Ribera, La Costra. Ningún barrio adicional ni reinterpretación de su posición se define en esta fase.

## Matriz para terminar el futuro plano urbano

| Campo | Pregunta técnica del inventario | Resultado |
|---|---|---|
| topology | Huella, costa y ríos concretos solo cuando existan geometrías verificadas | Necesita evidencia local y/o Core para materialización |
| housing | Residencia y hogares sujetos a derechos, ocupación y capacidad; población urbana no es número de viviendas | Necesita evidencia local y/o Core para materialización |
| goods | Entradas de mercancías sustentadas por cadena, permiso, stock y acceso; sin cargas conjuradas | Necesita evidencia local y/o Core para materialización |
| services | Proveedor real, localización, turno y aforo; necesidad no obliga a instalar institución | Necesita evidencia local y/o Core para materialización |

| law | Justicia del Rey, jurisdicción Casa-Corona y custodia diferenciadas; sin ley local propia | Necesita evidencia local y/o Core para materialización |
| fiscal | No aduanas entre Grandes Casas; control exterior solo donde está respaldado | Necesita evidencia local y/o Core para materialización |
| security | Autoridad de Guardia urbana, Casa y Armada Real separada; no nuevo cuerpo militar | Necesita evidencia local y/o Core para materialización |
| care | Salud, cuidados y dependencia sin hospital o cuidador universal por plantilla | Necesita evidencia local y/o Core para materialización |
| relationships | Core hereda parentesco, reputación, conocimiento, memoria, diálogo y consentimientos | Necesita evidencia local y/o Core para materialización |
| maintenance | Agua, saneamiento, incendios, desgaste y combustible solo con infraestructura específica o estado UNKNOWN | Necesita evidencia local y/o Core para materialización |
| worldstate | Entidades, ubicaciones, accesos, actividades y cambios persisten solamente cuando CoreRPG los ejecuta | Necesita evidencia local y/o Core para materialización |

La matriz permite **evaluar** decisiones futuras, pero no decreta físicamente un hospital, mercado, puente, puerto nuevo, aduana independiente, cuartel o barrio. Los sistemas universales como K, MEM, EMP, RES, OWN, WAIT, CARE y FIRE deben leerse desde Nimroel Core/Norgard, respetando el principio de no duplicación de Valrik.
