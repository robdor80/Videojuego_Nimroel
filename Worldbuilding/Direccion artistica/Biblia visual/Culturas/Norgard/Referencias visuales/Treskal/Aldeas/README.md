# Referencias visuales — Aldeas de Treskal

Esta carpeta almacenará las **referencias visuales aprobadas** de los modelos e instancias de aldeas Valrik.

## Estructura recomendada

```text
Aldeas/
├── V1_Mixta_maderera_agricola/
│   └── 01_Vista_aerea_canonica/
├── V2_Molino_agroganadera/
│   └── 01_Vista_aerea_canonica/
└── Instancias/
    └── <nombre_de_aldea>/
```

Cada referencia aprobada debe conservar, cuando corresponda:

- imagen;
- prompt realmente utilizado;
- revisión o notas de validación.

## Regla

Una imagen aérea canónica puede fijar identidad visual y relaciones espaciales generales, pero no sustituye automáticamente a un plano métrico para el motor.

Los planos funcionales pertenecen al modelo de aldea dentro del lore jugable.
