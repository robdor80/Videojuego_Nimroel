# Referencias visuales de Norgard

Las referencias visuales antiguas de asentamientos y ciudades de Norgard han sido retiradas del repositorio operativo al quedar superadas por el nuevo flujo de trabajo visual.

A partir de ahora, las referencias visuales maestras de ciudades y asentamientos se generarán exclusivamente a partir de descripciones canónicas detalladas y actualizadas.

## Política actual

- Los assets maestros originales se archivan externamente.
- El repositorio operativo conservará las versiones activas aprobadas en formato optimizado (WEBP), junto con sus prompts y metadatos asociados.
- Las referencias anteriores no se consideran canon visual vigente.

## Nota

La retirada de estas referencias no implica pérdida de histórico, ya que el control de versiones de Git conserva el registro de cambios y los assets maestros se archivan fuera del repositorio operativo.
