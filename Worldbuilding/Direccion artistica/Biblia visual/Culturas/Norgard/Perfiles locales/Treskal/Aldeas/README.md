# Perfil visual de aldeas — zona de Treskal

Esta carpeta contiene reglas visuales específicas para representar aldeas del **territorio de Treskal**, administrado por la Casa Valrik.

El perfil actualmente disponible, `TRESKAL_VILLAGE_VISUAL_PROFILE_v0.1.md`, tiene un alcance más limitado: es la **base visual de las aldeas interiores cercanas a Treskal representadas actualmente por los modelos V1 y V2**. No debe interpretarse automáticamente como perfil general de todas las aldeas del territorio.

## Herencia visual

Las reglas deben respetar, en este orden:

1. Biblia visual global de Nimroel.
2. Biblia visual de categoría **Asentamientos**.
3. Perfil visual de Norgard.
4. Perfil local de Treskal cuando corresponda.
5. Perfil visual específico aplicable a la aldea.
6. Perfil visual del modelo V1, V2, V3...
7. Prompt final.
8. Imagen o asset.

## Separación

Aquí se define **cómo deben verse las aldeas dentro del alcance de cada perfil visual aprobado**.

La lógica territorial y jugable pertenece a:

`Worldbuilding/Reinos/Reinos de los Hombres/Norgard/Territorios/Casa Valrik/Aldeas/`

Los prompts pertenecen a:

`Worldbuilding/Direccion artistica/Prompts maestros/Asentamientos/Norgard/Treskal/Aldeas/`

Las imágenes aprobadas pertenecen a:

`Worldbuilding/Direccion artistica/Biblia visual/Culturas/Norgard/Referencias visuales/Treskal/Aldeas/`
